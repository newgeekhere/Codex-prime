# Premier projet

Premier projet web du dépôt **Codex-prime** : une page web statique simple et responsive, prête à être publiée avec GitHub Pages.

## Structure

```text
premier-projet/
├── .nojekyll
├── README.md
├── index.html
└── style.css
```

## Technologies

- HTML5
- CSS3
- Aucun framework
- Aucune dépendance

## GitHub Pages

Le fichier `.nojekyll` indique à GitHub Pages de servir les fichiers statiques directement, sans traitement Jekyll.

Pour publier le site, configure GitHub Pages depuis les paramètres du dépôt et utilise la branche `main` comme source de déploiement.

Une fois GitHub Pages activé pour le dépôt, cette page pourra être accessible sous le chemin `/Codex-prime/premier-projet/`.

## Objectif

Ce projet sert de première base pour apprendre à créer, versionner et publier progressivement des projets web avec GitHub et Codex.
