# Codex Prime — Premier projet

Première page web statique du dépôt **Codex-prime**, prête à être publiée avec GitHub Pages.

## Structure

```text
Codex-prime/
├── .nojekyll
├── README.md
├── index.html
└── style.css
```

## Technologies

- HTML5
- CSS3
- Aucun framework
- Aucune dépendance

## GitHub Pages

Le site est conçu pour être publié directement depuis la racine de la branche `main`.

Dans GitHub : **Settings → Pages → Build and deployment → Deploy from a branch**, puis sélectionner **main** et **/(root)**.

Adresse prévue : `https://newgeekhere.github.io/Codex-prime/`
